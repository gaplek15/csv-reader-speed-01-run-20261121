A faster drop-in for make.fun's csv-reader 1.0.0: reads broken CSV files exactly as the reference does (quoted fields, doubled quotes, stray CRs, unterminated quotes, short/long rows), about 3x faster than the house baseline on the practice set. solve.js is a dependency-free ES module exporting run(input); main.ts reads /input/cases.json, answers each case with run, and writes /output/answers.json.

## Run it

```sh
node main.ts
```
